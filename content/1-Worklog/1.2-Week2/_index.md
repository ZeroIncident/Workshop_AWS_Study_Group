### Week 2 Objectives:

* Learn how AWS services support application scalability, operational monitoring, DNS, data storage, caching, and content delivery.
* Practice navigating service configurations and relating each service to its role in an application architecture.
* Develop familiarity with the AWS CLI as an additional way to manage and inspect AWS resources.

### Week 2 Achievements:

* Learned how EC2 Auto Scaling, CloudWatch, and Route 53 can support available and observable workloads.
* Practiced reviewing AWS CLI settings, DynamoDB tables, ElastiCache options, and CloudFront distribution configurations.
* Improved understanding of Windows workloads, directory services, and the components used to design highly available web applications.
