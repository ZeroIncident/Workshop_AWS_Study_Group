### Week 3 Objectives:

* Understand the basic approaches for migrating virtual machines and databases to AWS, including planning for disaster recovery.
* Learn how automation, monitoring, tags, and systems-management tools help operate AWS environments consistently.
* Build introductory infrastructure-as-code skills by working with CloudFormation and AWS CDK concepts.

### Week 3 Achievements:

* Reviewed migration requirements for virtual machines and databases, then created a basic plan for disaster recovery.
* Practiced using Lambda, CloudWatch, Grafana, resource tags, Systems Manager, and Session Manager in operational scenarios.
* Gained foundational experience reading CloudFormation templates and creating a basic AWS CDK project.
