### Week 5 Objectives:

* Learn how AWS security services protect user identities, applications, data, storage, and infrastructure.
* Understand how preventive controls, monitoring services, and alerting tools work together in a cloud security strategy.
* Practice reviewing security configurations and findings so that risks can be identified and addressed early.

### Week 5 Achievements:

* Practiced reviewing IAM policies, Security Hub findings, VPC endpoint policies, WAF rules, and KMS key settings.
* Explored services for sensitive-data discovery, secret storage, centralized firewall governance, threat detection, and patch management.
* Improved understanding of Cognito authentication and the security practices needed to protect Amazon S3 resources.
