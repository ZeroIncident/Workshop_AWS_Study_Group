### Week 6 Objectives:

* Learn reliability patterns for protecting data, connecting networks, coordinating messages, and maintaining application availability.
* Explore high-availability approaches for Windows and SQL Server workloads running on AWS.
* Develop introductory container skills with Docker, Amazon ECS, and infrastructure-as-code tools for container deployments.

### Week 6 Achievements:

* Practiced creating backup and messaging configurations while reviewing VPC peering, Transit Gateway, and EBS Multi-Attach options.
* Improved knowledge of database and Windows failover patterns, including SQL Server high-availability deployment considerations.
* Built introductory Docker and ECS skills by reviewing task definitions and ECS infrastructure defined with AWS CDK.
